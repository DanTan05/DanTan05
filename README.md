## 🚀 Featured Projects

### 🛒 [Olist Data Platform](https://github.com/DanTan05/olist-data-platform)
Data pipeline on ~100k Brazilian e-commerce orders: raw CSVs → Bronze / Silver / Gold Delta tables in PySpark on Databricks → star schema → Power BI dashboard. Includes data checks (row counts, unique keys, no orphan rows) and revenue reconciliation across tables.
**Finding: late deliveries average 2.56★ vs 4.29★ on time**
`PySpark` `Databricks` `Delta Lake` `Spark SQL` `Power BI` `DAX`

### 📧 [Order Email Automation](https://github.com/DanTan05/order-email-automation)
Turns customer order emails into a checked order list in Google Sheets. Gemini extracts the order lines into a fixed schema; pandas checks them against business rules and the product catalog; clean lines and lines needing review go to separate tabs.
**Structured LLM output · rule-based validation · 7 unit tests**
`Python` `Gemini API` `pydantic` `pandas` `Google Sheets API` `pytest`

### ♻️ [Smart Recycling Bin: AI Classifier](https://github.com/DanTan05/smart-bin-classification-pipeline)
Team project: a smart waste-segregation bin. I built the computer-vision software, which classifies items into 5 categories, routes them, and flags hazardous batteries.
**MobileNetV2 (transfer learning) · 99.3% test accuracy · TFLite on Raspberry Pi 5**
`Python` `TensorFlow` `MobileNetV2` `TFLite` `OpenCV`

### 🚗 [UAE Used Car Price Predictor](https://github.com/DanTan05/Used_Car_Price_Predictor_UAE)
Predicts used-car prices in AED from 9,742 listings, with 28 features (17 engineered), model comparison and SHAP explanations.
**XGBoost · MAE AED 36,985 · R² 0.50**
`Python` `XGBoost` `scikit-learn` `SHAP`

### 💬 [Sentiment Analyser (NLP)](https://github.com/DanTan05/sentiment-analyser) · [🤗 Live Demo](https://huggingface.co/spaces/DanTan05/sentiment-analyser)
Web app classifying text as positive / negative / neutral, with word-level highlighting of what drove each prediction.
**TF-IDF baseline (~90%) vs fine-tuned DistilBERT (~93–95% on IMDB) · deployed on Hugging Face Spaces**
`Python` `Transformers` `DistilBERT` `scikit-learn` `Gradio`

### 📉 [du Customer Churn Prediction](https://github.com/DanTan05/du-churn-prediction)
Team project predicting telecom customer churn, comparing four models, with a Streamlit app for single and batch predictions.
**Logistic Regression · Random Forest · XGBoost · Neural Network (MLP)**
`Python` `scikit-learn` `XGBoost` `Streamlit`
